# Contributing to prime

Thank you for your interest in contributing to Lineage Foundation **prime** (2-Way chain library).

## How to contribute

1. **Open an issue** – For bugs, features, or questions, open an issue in this repository.
2. **Fork and clone** – Fork the repo and clone it locally.
3. **Create a branch** – Use a descriptive branch name (e.g. `feat/add-x`, `fix/issue-y`).
4. **Make changes** – Follow [.editorconfig](.editorconfig). Run `cargo fmt` and `cargo clippy` where applicable.
5. **Run tests** – `cargo test` (and `cargo build` for release checks).
6. **Submit a PR** – Open a pull request against `main`.

## Code style

- Follow [EditorConfig](.editorconfig); Rust uses 4-space indentation.
- Use [Conventional Commits](https://www.conventionalcommits.org/) for commit messages.

## Pull request process

- PRs require review where branch protection applies.

## Questions?

See [lineage.foundation](https://lineage.foundation).
